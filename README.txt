NPFA WEBSITE UPGRADE

Files in this package:
- index.html (updated homepage with official crest and gallery)
- assets/ (crest and four academy photos)

ANDROID / GITHUB INSTALLATION
1. Open your GitHub repository and create/open the assets folder.
2. Upload all five JPG files from the assets folder in this package into the repository's assets folder.
3. Open the repository's index.html, replace its contents with this package's index.html, and commit.
4. Do not delete admin-config.js, admin-login.html, admin-dashboard.html, or other existing files.
5. Refresh the public website after GitHub Pages deploys.

The homepage keeps the existing Supabase data-loading code. Coach profile cards will continue to use photo_url from the coaches table when a coach photo is configured there. The gallery uses the supplied academy photographs.
