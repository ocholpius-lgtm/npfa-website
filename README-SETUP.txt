NAIVASHA PREMIER SOCCER ACADEMY WEBSITE
========================================

WHAT IS INCLUDED
- index.html: public academy website
- styles.css: responsive styling for phones, tablets and computers
- script.js: mobile navigation and current year
- admin-dashboard.html: dashboard preview (not connected to a live database)
- assets/: folder reserved for the academy's approved crest and images

HOW TO VIEW ON ANDROID
1. Download and extract the ZIP file using your phone's Files app.
2. Open the extracted folder.
3. Tap index.html. If your phone offers a browser, choose Chrome.
4. Some Android file managers restrict local website features. If it does not display correctly, use a trusted static hosting service with help from an authorised adult.

BEFORE PUBLISHING
1. Replace the text-based NPFA crest with the academy's approved logo file if desired.
2. Replace the placeholder email link in index.html with an official academy contact address.
3. Confirm all academy descriptions, age groups and contact details with the academy.
4. Add only photographs that the academy is authorised to publish and for which appropriate parent/guardian permission has been obtained.
5. Have an authorised adult review safeguarding, privacy and contact procedures.

DATABASE AND STAFF ACCESS
The admin-dashboard.html page is a visual preview only. It does not save data, authenticate staff or connect to Supabase.
An authorised adult academy administrator should own and configure the Supabase project, invite staff, review the SQL policies, enable multi-factor authentication where available, and test access controls before any real information is used.
Never put a Supabase service-role/secret key in website JavaScript or a public website.
Do not collect children's full names, dates of birth, addresses, personal phone numbers, medical information or photographs unless the academy has a lawful, necessary, documented process and appropriate consent.
Use sample data during development. Restrict access to player information and future fixture details. Remove staff access promptly when roles end.

IMPORTANT
This is a starter website package, not a production-certified safeguarding, privacy or database system.
